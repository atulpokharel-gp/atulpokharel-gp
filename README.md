## 🛡️ groundre  <sub>— current focus</sub>

### The deterministic trust layer for AI-generated security findings.

<!-- TODO: replace the # links below with your groundre live-demo / GitHub repo URL, then add a preview image like the others -->

[![AI Security](https://img.shields.io/badge/AI-Security%20Verification-ef4444?style=for-the-badge)](#)
[![Zero-Trust LLM](https://img.shields.io/badge/Zero--Trust-LLM-0f172a?style=for-the-badge)](#)
[![Ghidra + radare2](https://img.shields.io/badge/Ghidra%20%2B%20radare2-Ground%20Truth-2563eb?style=for-the-badge)](#)

### What it does

AI now writes reverse-engineering and vulnerability reports faster than anyone can verify them — the curl project even shut down its bug bounty over "AI slop." groundre re-derives **every claim** from the actual binary using Ghidra + radare2 and returns **CONFIRMED / CONTRADICTED / UNVERIFIED** with the exact evidence (addresses, APIs, certificates).

### Core Idea

> You can't verify an LLM with an LLM for a security decision.
> An AI agent may **propose** claims — deterministic verifiers **dispose**.
> **No model sits in the verdict path.**

### Key Features

| Feature | Purpose |
|---|---|
| 🧾 Deterministic verifiers | Prove each claim against ground truth — reproducible, auditable |
| 🔍 Ground-truth engine | Ghidra + radare2 recover functions, calls, strings, xrefs |
| 🛂 Provenance & signing | Authenticode / PKCS#7 leaf-signer + chain validation |
| 🌐 Fact-based IOCs | Validated against IANA/RFC, tiered by the binary's own evidence |
| 🚦 Release gate | PASS / REVIEW / FAIL, with evidence for every verdict |

### Tech Direction

`Ghidra` • `radare2` • `Zero-Trust LLM Agents` • `FastAPI` • `Next.js` • `CLI` • `MCP Server` • `GitHub Action` • `Deterministic Verification`
