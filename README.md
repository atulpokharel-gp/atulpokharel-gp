### What it does

Smart365Guide helps users understand and complete complex workflows inside existing software.

Instead of replacing an ERP or SaaS system, Smart365Guide sits on top of it and makes it intelligent.

### Core Idea

> Uber does not own cars.  
> Airbnb does not own hotels.  
> Smart365Guide does not own your ERP.  
> **It makes your ERP intelligent.**

### Key Features

| Feature | Purpose |
|---|---|
| 🧠 Explain Mode | Explains screens, fields, buttons, and business rules |
| 🧭 Guide Mode | Walks users step by step through workflows |
| ⚡ Do Mode | Helps users complete actions with approval and verification |
| 📚 Knowledge Layer | Converts process knowledge into reusable AI guidance |
| 🔐 Safe Actions | Uses human approval for sensitive or risky operations |

### Built For

- ERP systems
- SaaS dashboards
- Internal tools
- Operations teams
- Support-heavy products
- Training-heavy workflows
- Complex business software

### Tech Direction

`LLMs` • `RAG` • `Workflow Automation` • `JavaScript SDK` • `Human-in-the-Loop AI` • `Context Engineering` • `ERP Intelligence`

## 🤖 MomoBot

### Secure AI agent platform for safe workflow execution.

<a href="https://momobot-sigma.vercel.app/">
  <img src="https://image.thum.io/get/width/1200/crop/700/https://momobot-sigma.vercel.app/" width="100%" alt="MomoBot Live Website Preview" />
</a>

<br />

[![Live Website](https://img.shields.io/badge/Live%20Website-momobot--sigma.vercel.app-22c55e?style=for-the-badge&logo=vercel&logoColor=white)](https://momobot-sigma.vercel.app/)
[![AI Agents](https://img.shields.io/badge/AI-Agent%20Platform-ef4444?style=for-the-badge)](#)
[![Secure Automation](https://img.shields.io/badge/Secure-Automation-2563eb?style=for-the-badge)](#)

### What it does

MomoBot is a secure AI agent and workflow automation platform focused on controlled execution.

It is designed for real-world automation where actions need to be safe, traceable, approved, and auditable.

### Core Idea

> AI agents should not just be powerful.  
> They should be controllable, observable, and safe to deploy.

### Key Features

| Feature | Purpose |
|---|---|
| ✅ Approval Gates | Keeps sensitive actions under human control |
| 🔐 Secure Execution | Runs only allowed tasks and workflows |
| 📜 Audit Logs | Tracks what happened, when, and why |
| 🔁 Workflow Orchestration | Coordinates multi-step automation tasks |
| 🧠 Agent Control Layer | Lets AI reason while execution stays governed |
| 👥 Role-Based Control | Supports controlled access and permissions |

### Built For

- AI agents
- Workflow automation
- Secure task execution
- Enterprise automation
- Human-in-the-loop systems
- Controlled agent operations
- Automation dashboards

### Tech Direction

`AI Agents` • `FastAPI` • `WebSockets` • `RBAC` • `Audit Logs` • `Task Execution` • `Human-in-the-Loop Automation` • `Secure AI Workflows`
